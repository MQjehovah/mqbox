# Everything 插件架构说明

> 基于代码和设计文档整理，2026-07-15

## 架构概览

Everything 插件采用 **三层架构**：

```
┌─────────────────────────────────────────────────────┐
│                     MQBox 主应用                      │
│   ┌──────────────────────────────────────────────┐   │
│   │           插件管理器 / 搜索框架               │   │
│   │  ┌─────────┐  ┌──────────┐  ┌──────────┐   │   │
│   │  │ 命令系统 │  │ 搜索入口  │  │ 存储系统 │   │   │
│   │  └────┬────┘  └────┬─────┘  └────┬─────┘   │   │
│   └───────┼─────────────┼─────────────┼─────────┘   │
└───────────┼─────────────┼─────────────┼─────────────┘
            │             │             │
    ┌───────▼─────────────▼─────────────▼───────────┐
    │           Everything 插件（index.ts）           │
    │  ┌──────────────┐  ┌──────────────────────┐   │
    │  │ 命令注册层    │  │ 配置管理层             │   │
    │  │ - search     │  │ - loadConfig()       │   │
    │  │ - saveConfig │  │ - saveConfig()       │   │
    │  │ - 搜索提供者  │  │ - context.storage    │   │
    │  └──────┬───────┘  └──────────┬───────────┘   │
    │         │                     │                │
    │  ┌──────▼─────────────────────▼───────────┐   │
    │  │        ETP 客户端（everything.ts）       │   │
    │  │    search(query, options) → 结果        │   │
    │  └────────────────┬───────────────────────┘   │
    └───────────────────┼───────────────────────────┘
                        │ ETP 协议（TCP :26983）
    ┌───────────────────▼───────────────────────────┐
    │            Everything 桌面应用                  │
    │           (ETP 服务，v1.5+)                    │
    └───────────────────────────────────────────────┘
```

## 模块职责

### 1. 插件入口层（`src/index.ts`）

**角色：** MQBox 插件生命周期管理

| 功能 | 说明 |
|------|------|
| `activate()` | 注册命令、加载配置、注册搜索提供者 |
| `deactivate()` | 清理资源 |
| 命令 `search` | 接收搜索框输入 → 调 ETP 客户端 → 返回结果 |
| 命令 `saveConfig` | 接收配置 → 持久化到 `context.storage` |
| SearchProvider | 暴露搜索接口给全局搜索框 |

**依赖：** MQBox Context API（`context.commands`, `context.storage`, `context.search`）

---

### 2. ETP 客户端（`src/everything.ts`）

**角色：** Everything ETP 协议通信

| 函数 | 说明 |
|------|------|
| `search(query, options?)` | 核心搜索函数。建立 TCP 连接、发送 ETP 查询、解析结果 |

**设计决策：**
- 所有错误静默处理（返回空数组），避免搜索框抖动
- 使用 `options` 参数传递连接配置，与配置分离
- 不持久化状态，每次搜索独立连接

---

### 3. 配置界面（`src/Config.vue`）

**角色：** 可视化配置管理

| 功能 | 说明 |
|------|------|
| 加载配置 | 从 `context.storage` 读取已有配置 |
| 表单编辑 | 修改端口/超时/最大结果数 |
| 保存配置 | 调用 `saveConfig` 命令持久化 |
| 校验 | 前端校验输入范围 |

**技术选型：** Vue 3 + 单文件组件（SFC），由 Vite 独立打包为 `dist/Config.js`

---

## 数据流

### 搜索流程

```
用户输入 "report.pdf" + Enter
        │
        ▼
MQBox 搜索框架 → 调起 Everything 插件的 search 命令
        │
        ▼
index.ts search() → 读取配置 → everything.ts search()
        │                           │
        ▼                           ▼
返回 SearchResult[]     ETP TCP → Everything 桌面端
        │                           │
        ▼                           ▼
搜索框展示结果         Everything 返回文件名匹配列表
```

### 配置保存流程

```
用户在 Config.vue 修改配置 → 点击「保存」
        │
        ▼
Config.vue 调用 context.invokeCommand('saveConfig', config)
        │
        ▼
index.ts saveConfig() → context.storage.setItem('config', json)
        │
        ▼
存储成功 → 通知 Config.vue → 显示保存成功提示
```

## 模块边界

| 边界 | 归属 | 不归属 |
|------|------|--------|
| ETP 协议通信 | `everything.ts` | `index.ts` |
| 配置持久化 | `index.ts` | `Config.vue` |
| UI 渲染 | `Config.vue` | `index.ts` |
| 命令注册 | `index.ts` | `Config.vue` |
| 配置校验 | `Config.vue`（前端） | `everything.ts` |

## 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 配置存储方式 | MQBox `context.storage` | 统一存储 API，无需自建文件读写 |
| 配置界面框架 | Vue 3 独立组件 | MQBox 插件标准，可热加载 |
| ETP 错误处理 | 静默忽略 → 空数组 | 搜索框使用体验优先 |
| 连接方式 | 每次搜索新建 TCP 连接 | 简单可靠，无状态管理开销 |
